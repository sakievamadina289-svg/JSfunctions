# Задания

Решайте задания самостоятельно, затем сверьтесь с файлами в `solutions/`.
Каждое задание можно проверить запуском файла через `node`.

## Задание 1 — Приветствие
Напишите функцию `greet(name)`, которая выводит `Hello, <name>!`. Если имя не передано, по умолчанию используйте `"Guest"`.

## Задание 2 — Калькулятор
Напишите функции-объявления `add`, `subtract`, `multiply`, `divide`. `divide` должна возвращать `null` при делении на ноль (без вывода в консоль).

## Задание 3 — Площадь через выражение
Создайте функцию-выражение `area`, которая принимает ширину и высоту прямоугольника и возвращает площадь.

## Задание 4 — Стрелочные функции
Перепишите следующую функцию в стрелочную форму с одним выражением:
```js
function isEven(n) {
  return n % 2 === 0;
}
```

## Задание 5 — Сумма через rest
Напишите функцию `sumAll(...nums)`, которая возвращает сумму всех аргументов. Для пустого вызова вернуть `0`.

## Задание 6 — Пользователь
Напишите функцию `createUser(name, group = "SE-101")`, которая возвращает объект `{ name, group, createdAt }`, где `createdAt` — текущая дата.

## Задание 7 — Коллбэк
Напишите функцию `forEachTimes(times, action)`, которая вызывает `action(i)` для `i` от `0` до `times - 1`. Вызовите её с коллбэком, выводящим квадрат `i`.

## Задание 8 — Фабрика множителей
Напишите функцию `makeMultiplier(n)`, которая возвращает функцию, умножающую аргумент на `n`. Создайте `double` и `triple`.

## Задание 9 — Счётчик
Напишите функцию `createCounter(start = 0)`, которая возвращает объект с методами `increment()`, `decrement()` и `value()`. Состояние должно храниться в замыкании.

## Задание 10 — Чистая или нечистая?
Для каждой функции определите, чистая она или нет, и объясните почему в комментарии:
```js
function f1(a, b) { return a * b; }
function f2(arr) { arr.push(1); return arr; }
function f3() { return Math.random(); }
function f4(x) { console.log(x); return x; }
```

## Задание 11 — Hoisting
Что выведет следующий код и почему? Ответ запишите в комментарии, затем проверьте запуском:
```js
console.log(first());
console.log(second());

function first() { return "first"; }
var second = function () { return "second"; };
```
